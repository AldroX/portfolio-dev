**Backend Developer**

API RESTful desarrollada con **NestJS y TypeScript** para la gestión de eventos, miembros, patrocinadores, videos y usuarios, implementando una arquitectura modular y un sistema de autenticación y autorización basado en JWT y roles.

- Desarrollo de módulos independientes para **autenticación, usuarios, eventos, miembros, patrocinadores y videos**.
- Implementación de APIs REST utilizando **Controllers, Services, DTOs y Guards**, aplicando separación de responsabilidades.
- Implementación de autenticación mediante **JWT/Passport** y autorización basada en roles mediante `JwtAuthGuard` y `RolesGuard`.
- Desarrollo de operaciones CRUD para la gestión de usuarios y entidades principales del sistema.
- Implementación de relaciones **1:N y N:M** mediante **Prisma ORM y PostgreSQL**.
- Modelado de la relación entre eventos y patrocinadores mediante una tabla intermedia con **clave primaria compuesta**.
- Implementación de endpoints para la asignación y eliminación de patrocinadores asociados a eventos.
- Implementación de carga y validación de imágenes mediante **Multer e interceptores personalizados**.
- Validación de datos mediante **class-validator y class-transformer**.
- Documentación de la API mediante **Swagger/OpenAPI**.
- Configuración del entorno de ejecución mediante **Docker Compose**, incluyendo PostgreSQL, migraciones de Prisma y persistencia de datos.

**Tecnologías:** NestJS, TypeScript, Prisma, PostgreSQL, JWT, Passport, Swagger/OpenAPI, class-validator, Multer, Docker, Docker Compose.
